Mise en place

  1. Crée une application sur le portail développeur Discord.
  2. Onglet OAuth2 : copie le Client ID et le Client Secret.
  3. OAuth2 → Redirects : ajoute http://localhost puis Save.
  4. Colle-les ci-dessous et autorise : accepte la fenêtre qui s'ouvre dans Discord.
